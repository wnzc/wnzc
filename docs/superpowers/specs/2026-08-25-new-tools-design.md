# 六个新工具设计稿（newTools）

日期：2026-08-25 ｜ 状态：已确认（用户批准，新增独立目录要求）

## 背景与目标

为「蜗牛工具箱」新增 6 个小工具。用户为唯一使用者，部署于 GitHub Pages，
无自有域名；AI 调用维持前端直连方案（见仓库根 `ai-models.js` + `src/ai-config.js`）。
新工具统一放入 `src/newTools/` 目录以便后续持续追加。

## 共用约定

- 单文件 HTML 自包含；暗色卡片视觉（渐变 `#1e1e2e→#2d2d44`、强调色 `#ff9800`）；移动端优先 max-width 480px。
- AI 页引入 `../../ai-models.js`、`../ai-config.js`、`../ai-history.js`，使用全局
  `API_URL / API_HEADER / GLM_MODEL / VOICE_API_URLS`；流式 SSE 输出；TTS 朗读；
  结果经 `aiHistory.save()` 入历史。交互骨架参考 `src/hypnosis.html`。
- 纯本地页数据存 localStorage；内置数据页在文件头注释更新方法。

## 工具明细

### 1. countdown.html 倒数日（纯本地）
- 添加事件：名称 + 目标日期 + 「每年重复」复选框；localStorage 键 `countdown_events_v1`。
- 卡片列表按剩余天数升序；大数字显示「N 天」；每年重复的事件自动指向下一次周年日；
  过期事件显示「已 N 天」灰化；支持删除。

### 2. unit.html 单位换算（纯本地）
- 分类 Tab：长度/重量/温度/面积/体积/速度/数据大小；每类常用单位全。
- 双栏「从/到」+ 实时互转 + 一键交换；温度用公式换算，其余乘系数。

### 3. holiday.html 节假日助手（内置数据零请求）
- 文件顶部常量区内置当年法定节假日与调休上班表；实现时通过 haoshenqi/bitefu
  免费接口逐日校验后再写入，并在注释中说明每年更新方法。
- 顶部状态卡：「今天是工作日/周末/假期」+「距离下一个假期还有 N 天」大数字；
  下方全年假期列表（名称/放假区间/天数/调休提示）。

### 4. dream.html AI 解梦（AI）
- 输入梦境描述 → 流式输出四段：【梦境回放】【象征解读】【情绪洞察】【一句建议】。
- 系统提示词定位：温和风趣的解梦师；轻量引用心理学象征（弗洛伊德/荣格常识级）；
  明确娱乐向、不判定吉凶祸福、不迷信恐吓。
- TTS 整篇朗读；历史记录保存。

### 5. fridge.html 冰箱料理（AI）
- 食材输入（逗号/空格分隔转 chips 可删）+ 口味偏好下拉 + 忌口输入。
- 流式输出三道菜：菜名 / 推荐理由 / 还缺的食材 / 简明步骤。
- 历史记录保存；TTS 可选朗读当前菜谱。

### 6. naming.html AI 起名（AI）
- 表单：类型（宝宝名/网名/宠物名）+ 姓氏（宝宝名时必填）+ 性别 + 风格
  （诗经楚辞/武侠古风/现代简约/可爱萌系/霸气）+ 生成数量固定 8 个。
- 流式输出编号列表：名字 + 拼音 + 寓意解释；完成后逐行点击复制 + 整体复制。
- 历史记录保存。

## 实施顺序

countdown → unit → holiday（自研）；dream / fridge / naming（并行子代理开发）。
全部完成后由主会话统一注册进 `index.html` 的 toolsData 并做全量验证。

## 验收标准

- 每个页面手机宽度可直接打开使用，无控制台报错；JS 通过 node --check。
- AI 三页在真实 key 下可流式出内容、可朗读、历史面板正常。
- holiday 数据与官方公告一致；countdown/unit 在刷新与重启后数据保持。
